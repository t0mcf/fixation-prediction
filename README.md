# Scaling and Transfer of Synthetic Data for Scanpath Prediction

Code and results of the bachelor's thesis. The thesis trains three
scanpath-prediction models (a model developed for the thesis, DeepGaze III
and ScanDiff) on increasing amounts of synthetic scanpaths from a foveated
active-vision model, and tests whether this synthetic pretraining improves
the prediction of human scanpaths on MIT1003, with and without
COCO-FreeView as additional human training data.

All numbers and figures in the thesis are computed from the CSV files in
`docs/report_tables/`. `docs/number_provenance.md` lists, for every reported
number, the file and column it comes from.

## Setup

```bash
conda env create -f envs/environment_praktikum.yml   # our model, DeepGaze III, evaluation, tables, figures
conda env create -f envs/environment_scandiff.yml    # ScanDiff and the whole-scanpath scoring
```

The experiments ran on a Slurm cluster. Scripts refer to data, checkpoints
and the ScanDiff working copy by absolute paths on that cluster (for example
`SD` in `scripts/aggregate_v2_results.py` and the `--parquet-path` arguments
in `slurm/`); these have to be adapted to re-run the pipeline elsewhere.

## Data

Data and model checkpoints are not included.

- **Synthetic scanpaths.** For every ImageNet-1K training image, 16
  scanpaths of 16 fixations generated by the active-vision model of
  Hassler et al. (2026) on 224 × 224 center crops, each starting at the
  image center.
- **Human gaze.** MIT1003 and COCO-FreeView in the format distributed with
  ScanDiff.
- **Splits** (`data/splits_v2.tar.gz`, checksums in `data/splits_v2.sha256`):
  - `imagenet_av/`: nested training sets of 1,000 to 800,000 images, 5,000
    validation and 10,000 test images, and the indices of the scanpaths used
    for training (5 of 16) and evaluation (all 16);
  - `mit1003/`: the split of the ScanDiff authors (702 / 150 / 151 images);
  - `coco_freeview/`: the COCO-FreeView split; only its training set is used.
- **Checkpoints.** The test manifests `docs/report_tables/*manifest*.json`
  record the sha256 of every checkpoint that entered a test evaluation.

## Pipeline

1. **Synthetic training.** Our model: `slurm/v2_ladder.sh` (training-set
   size, seed; `HFLIP=1` for the horizontal-flip control),
   `slurm/v2_800k_36ep_control.sh` for the extended-training control.
   DeepGaze III and ScanDiff: see `third_party/`.
2. **Human-gaze training.** Our model on MIT1003: `slurm/ft_authsplit.sh`;
   MIT1003 together with COCO-FreeView: `slurm/ft_joint_mit_coco.sbatch`.
   Comparison of synthetic sources: pretraining with `slurm/triangle_v2.sh`
   on corpora built by `scripts/build_av_fixed5_parquets.py`.
3. **Checkpoint selection and test evaluation.** Checkpoints are selected on
   validation data and recorded in a manifest before any test data is read
   (`scripts/prepare_*.py`, checked by `scripts/check_*.py`). The test runs
   (`scripts/run_frozen_indomain_v3.py`, `scripts/run_frozen_transfer.py`)
   evaluate only the recorded checkpoints, using
   `scripts/eval_synthetic_fair.py` on the synthetic data and
   `scripts/eval_mit1003_fair.py` on MIT1003. The generator reference is
   computed by `scripts/nss_ceiling.py`.
4. **Whole-scanpath evaluation.** Scanpaths of our model are generated by
   `scripts/sample_for_eval.py` (`slurm/sample_ours_*.sh`) and scored with
   `tools/score_scanpaths.py` from `third_party/scandiff/`, the same scorer
   as for DeepGaze III and ScanDiff.
5. **Tables and figures** (CPU only):

   ```bash
   python scripts/aggregate_v2_results.py --split test     # docs/report_tables/*_test.csv
   python scripts/make_control_tables.py                   # best_epoch_v2.csv, fulltest_control_test.csv
   python scripts/make_length_control_table.py             # length_control_test.csv
   python scripts/scanpath_geometry.py                     # scanpath_geometry*.csv
   python scripts/make_thesis_tables_v2.py --split test    # thesis_tables_test.tex
   python scripts/plot_thesis_fig<name>.py --split test    # docs/figures_thesis/
   ```

## Names used in files and tables

| Name | Meaning |
|---|---|
| `v2` | the final experimental protocol (splits and settings of the thesis) |
| `bv<size>`, e.g. `bv800k` | our model trained on human gaze after synthetic pretraining on `<size>` images (initialized from the best-validation checkpoint) |
| `full<size>` | the same for DeepGaze III |
| `av_pretrained` | the same for ScanDiff |
| `scratch` | human-gaze training without synthetic pretraining |
| `joint_…` | human-gaze training on MIT1003 together with COCO-FreeView |
| `fair_fixedsplit` | conditional evaluation on the fixed MIT1003 split with the shared evaluator |
| `realism` | in-domain whole-scanpath similarity (400-image test subset) |
| `xfam` | whole-scanpath similarity on MIT1003 for all three models |
| `triangle`, `sd5`, `avfull`, `avmatch` | comparison of synthetic sources: ScanDiff-generated, active vision at full length, active vision cut to matched length |
| `ceiling` | the generating active-vision model as reference |
