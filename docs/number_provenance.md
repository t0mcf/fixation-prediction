# Number provenance

Every number reported in the thesis, with the file and aggregation that
produces it. Files are under `docs/report_tables/` unless stated otherwise.

Conventions:

- "mean over runs" is the arithmetic mean of the per-run values; the
  bracketed ranges in the thesis tables are min–max over runs.
- Whole-scanpath values (MM-KLD, SM-KLD) are first averaged over the two
  sampling draws of each run (`sampling_aggregation = mean_within_training_run`),
  then over runs.
- Conditional metrics on MIT1003 use the 224 × 224 grid (`res = 224`) and
  image-then-dataset averaging (`*_img` columns).
- All CSVs below are regenerated by `scripts/aggregate_v2_results.py --split test`
  unless another script is named.

## Methods

| Number | Source |
|---|---|
| MIT1003 split 702 / 150 / 151 | `data/splits_v2.tar.gz` → `mit1003/{train,validation,test}.txt` (split of the ScanDiff authors) |
| ImageNet splits (nested 1k … 800k, 5,000 validation, 10,000 test) | `data/splits_v2.tar.gz` → `imagenet_av/` |
| COCO-FreeView: 3,021 images, 33 excluded scanpaths, 6.5 % / 6.1 % truncated fixations | `COCOFreeView_fixations_train.json` (30,129 records); 6.5 % of the fixations after the initial one (our model), 6.1 % including it (ScanDiff); both keep 15 fixations after the start |
| Statistics sample 499,298 scanpaths / 100,000 images | manifest of the ScanDiff-generated corpus (`scandiffgen_official_v2_avcrop_100k_unfiltered/manifest.json`) |
| Trainable parameters: ours 5.9 M, ScanDiff 37.1 M, DeepGaze III 29,741 (20,488 in the first readout layer) | counted from the model definitions and checkpoints; DeepGaze III also matches the authors' released weights (`deepgaze3.pth`, 297,410 / 10 folds) |
