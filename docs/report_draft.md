## 1. Introduction

Human visual perception is an active process: the eyes do not passively capture a scene but move in a sequence of rapid jumps (saccades) and brief pauses (fixations), selectively sampling regions of interest. Predicting where a person will look next — given the image and the sequence of fixations they have already made — is the problem of *scanpath prediction*. It is relevant both as a scientific model of visual attention and as a practical tool for applications such as user interface design, image compression, and autonomous systems.

This internship was concerned with building a deep learning model for next-fixation prediction that can exploit large amounts of training data. The key motivation is scalability: state-of-the-art models such as DeepGaze III [CITE] achieve strong performance but their architectures are not designed to improve as more training data becomes available. The goal of this work was to design a model whose performance measurably increases as the training set grows, and to characterise how far this scaling extends.

Training data was provided in the form of synthetic scanpaths generated by an active inference model [CITE] applied to ImageNet images. This dataset contains approximately 20 million scanpaths across roughly 1.28 million images, offering an unusually large source of supervision.

## 2. Related Work

**Fixation prediction** has traditionally been approached as static saliency estimation — predicting a single heatmap over the image without conditioning on fixation history. Models such as DeepGaze II [CITE] and SALICON [CITE] achieve strong results on benchmark datasets by learning to weight features from a frozen deep network.

**Scanpath prediction** is a harder problem: the model must additionally account for where the observer has already looked. DeepGaze III [Kümmerer et al., 2022] extends the DeepGaze framework to scanpath prediction by conditioning the predicted heatmap on the previous fixation locations via a learned inhibition-of-return mechanism. It uses a DenseNet backbone with a small readout network (~20k trainable parameters) and is trained by maximising the log-likelihood at true fixation locations. A key limitation of DeepGaze III for our purposes is that its small readout network is unlikely to improve substantially with more training data. Our model is designed to overcome this by using a larger, fully trainable architecture that processes scanpath history through a learned transformer and fuses it with image features via cross-attention.

## 3. Dataset

All experiments use synthetic scanpaths generated by an active inference model [CITE] applied to ImageNet [CITE] images. The dataset contains approximately 20.5 million scanpaths. Each scanpath consists of up to 16 fixation locations, represented as normalised (x, y) coordinates in $[-1, 1]^2$.

The dataset is split into training and validation subsets. Experiments use between 50 000 and 400 000 training images, with 16 or 8 scanpaths per image respectively. The validation set is held fixed across all experiments.

## 4. Model Architecture

The model takes an image and a sequence of past fixations as input and produces a log-probability heatmap over the image, representing the predicted distribution of the next fixation. A single forward pass produces all $T-1$ prediction steps simultaneously via causal masking. The architecture consists of four components.

### 4.1 Visual Encoder

A Vision Transformer (ViT-B/14) pre-trained with DINOv2 [Oquab et al., 2023] serves as the visual backbone. The encoder is kept **frozen** throughout training. For a 224×224 input image, it produces $N = 16 \times 16 = 256$ spatial patch tokens of dimension 768. A learned linear adapter projects these to the model's working dimension $d = 256$:

$$\mathbf{V} = \text{LayerNorm}(\mathbf{W}_\text{adapt} \cdot \text{DINOv2}(I)) \in \mathbb{R}^{N \times d}$$

### 4.2 Scanpath Encoder

The prefix of past fixations $\{(x_0, y_0), \ldots, (x_{T-1}, y_{T-1})\}$ is encoded into a sequence of tokens via a small causal transformer. Each fixation is projected to dimension $d$ and combined with learned step-index embeddings:

$$\mathbf{s}_t = \mathbf{W}_\text{coord} [x_t, y_t]^\top + \mathbf{e}_t$$

A two-layer causal transformer encoder processes the sequence with a causal attention mask, ensuring that token $t$ attends only to positions $0 \ldots t$. This prevents information leakage from future fixations during the predict-all training procedure. The output is a sequence of scanpath tokens $\mathbf{S} \in \mathbb{R}^{T \times d}$.

### 4.3 Cross-Attention Fusion

Four cross-attention fusion layers update the image patch tokens with information from the scanpath history. In each layer, image patch tokens serve as queries and scanpath tokens as keys and values:

$$\mathbf{V}' = \text{CrossAttention}(\mathbf{Q} = \mathbf{V},\ \mathbf{K} = \mathbf{V} = \mathbf{S}) + \text{FFN}$$

A key-padding mask zeroes out attention to scanpath positions beyond the valid prefix length. This produces history-conditioned image tokens: each patch representation is updated to reflect what has already been attended to in the scene.

### 4.4 Spatial Heatmap Decoder

The history-conditioned patch tokens are reshaped into a $16 \times 16$ spatial grid and decoded into a $64 \times 64$ log-probability heatmap through two rounds of nearest-neighbour upsampling followed by $3 \times 3$ convolution with Group Normalisation and GELU activations. A final $1 \times 1$ convolution produces a single-channel logit map, which is converted to log-probabilities via spatial log-softmax.

The choice of nearest-neighbour upsampling over bilinear or transposed convolution is motivated empirically: transposed convolution with stride 2 produces structural checkerboard artifacts due to non-overlapping kernel positions, while bilinear upsampling was found to run approximately 100× slower than expected on large tensors (see Section 5.2). Nearest upsampling followed by a learned convolution avoids both issues.

## 5. Training

### 5.1 Predict-All Formulation

A naive approach would sample one prediction step $t$ per scanpath per training step, using only 1 of the $T-1$ available supervision signals per scanpath. Instead, we adopt the **predict-all** formulation [cf. Kümmerer et al., 2022]: a single forward pass produces all $T-1=15$ heatmaps simultaneously, one for each step $t \in \{0, \ldots, T-2\}$. The causal mask in the scanpath encoder ensures that the prediction at step $t$ only sees fixations $0 \ldots t$. This provides up to 15× more gradient signal per scanpath.

### 5.2 Training Objective

Two loss functions were investigated.

**KL divergence.** A Gaussian heatmap $g_\sigma$ centred at the true fixation location (standard deviation $\sigma = 2$ pixels in 64×64 space) is used as a soft target. The loss is the KL divergence averaged over all valid (scanpath, step) pairs:

$$\mathcal{L}_\text{KL} = \frac{1}{|\mathcal{V}|} \sum_{(b,t) \in \mathcal{V}} \text{KL}(g_\sigma(\mathbf{f}_{b,t+1}) \| \hat{p}_{b,t})$$

**Negative log-likelihood (NLL).** The model is penalised by the negative log-probability assigned to the exact fixation pixel:

$$\mathcal{L}_\text{NLL} = -\frac{1}{|\mathcal{V}|} \sum_{(b,t) \in \mathcal{V}} \log \hat{p}_{b,t}(y_{t+1}, x_{t+1})$$

NLL avoids the $\sigma$ hyperparameter and provides a sharper training signal: the model is rewarded only for probability mass at the true location rather than in a neighbourhood around it. As shown in Section 6.2, NLL leads to substantially better evaluation performance.

### 5.3 Optimisation

All runs use AdamW with learning rate $3 \times 10^{-4}$, weight decay $0.01$, gradient clipping at norm 1.0, and cosine learning rate decay with a 5% linear warmup. Batch size is 128. Dropout of 0.1 is applied throughout the trainable components. Automatic mixed precision (AMP) is used throughout. The DINOv2 encoder is frozen and excluded from the optimiser.

### 5.4 Throughput Optimisations

Training on 200k+ images with batch size 128 and 15 prediction steps per scanpath requires careful engineering to be tractable. Three optimisations were applied:

**Vectorised prediction loop.** The original implementation iterated over the $T=15$ prediction steps in a Python loop, dispatching approximately 135 sequential CUDA kernel calls per training step. The GPU was idle for roughly 60% of each step waiting for the next Python call. The fix tiles the batch dimension from $(B, N, d)$ to $(B \times T, N, d)$ and processes all steps in a single pass. The causal constraint is encoded in a flat effective-length tensor:
$$\text{eff\_len}[b \cdot T + t] = \min(t + 1,\ \text{prefix\_len}_b)$$
This reduced backward CPU dispatch overhead from ~506ms to ~16ms per step (97% reduction).

**Nearest+conv decoder.** The bilinear upsampling layers in the decoder were found to run ~100× slower than the theoretical memory bandwidth limit on the large $(B \times T, C, H, W)$ tensors produced by the vectorised loop. Replacing them with nearest-neighbour upsampling followed by learned convolution eliminated this bottleneck and reduced CUDA time per step by 37%.

**DINOv2 deduplication.** With the grouped sampler (16 scanpaths per image), each batch of 128 samples contains only 8 unique images. Previously, DINOv2 ran on all 128 image tensors redundantly. Extracting the 8 unique images, running the encoder once, and tiling the result reduced encoder cost by 16×. Since `repeat_interleave` is differentiable, gradients still flow correctly through the image adapter.

The combined effect of these optimisations, together with AMP, increased training throughput from approximately 1 770 steps/hour to **7 200 steps/hour** — a 4× improvement.

## 6. Experiments and Results

### 6.1 Scaling with Training Data

To test whether the model improves with more data, we trained on 50k and 200k images with KL loss and $\sigma = 2.0$, evaluating NSS and AUC on the held-out validation set.

| Training images | Epochs | Best val NSS | Best val AUC |
|---|---|---|---|
| 50 000 | 15 | 3.35 (ep. 8) | 0.924 |
| 200 000 | 5 | 4.08 | 0.944 |
| 200 000 | 8 (ongoing) | 4.06 | 0.943 |

The 200k run at only 5 epochs already exceeds the 50k run at its best epoch by 22% on NSS. The 50k runs exhibit clear overfitting after epoch 7–8: validation NSS peaks then decreases while training loss continues to fall, indicating the model has begun to memorise training scanpaths. The 200k run shows no such plateau at epoch 8, suggesting the larger dataset provides sufficient regularisation.

### 6.2 Loss Function: KL Divergence vs. NLL

We trained two otherwise identical 200k/15-epoch runs with KL and NLL losses respectively. Results at epoch 8:

| Loss | Val NSS | Val AUC |
|---|---|---|
| KL (σ=2.0) | 4.06 | 0.943 |
| **NLL** | **4.43** | **0.947** |

NLL provides a consistent +0.37 improvement in NSS across all epochs. The gap appears from the first validation checkpoint and grows steadily, suggesting NLL provides a fundamentally better training signal rather than simply converging faster. This is consistent with the theoretical argument: KL against a Gaussian target trains the model to spread probability in a neighbourhood of the fixation, while NLL directly maximises probability at the true location — the same quantity that NSS measures.

Notably, the NLL run has *higher* validation KL than the KL run, yet better NSS and AUC. This confirms that KL against Gaussian targets is not aligned with the evaluation metrics of interest.

### 6.3 Scanpath Encoding Ablation: Visual Features

We investigated whether enriching the scanpath encoder with visual content at each fixation location would improve performance. For each past fixation, the DINOv2 patch feature at that location was looked up from the already-computed image tokens and added to the fixation embedding via a learned projection, at negligible computational cost.

| Model | Val NSS (ep. 8) | Val AUC (ep. 8) |
|---|---|---|
| Baseline (coordinates only) | 4.06 | 0.943 |
| + Visual features | 4.08 | 0.944 |

The improvement is marginal. We attribute this to redundancy: the cross-attention fusion already has access to the visual content at every past fixation location, because all 256 image tokens (including those at fixation positions) are in the key-value set. The explicit injection of visual features into the scanpath tokens does not provide information the model could not already access implicitly. A more effective design might compute explicit similarity scores between each image patch and each past-fixation patch, but this was not explored.

### 6.4 Sigma Ablation

A run with $\sigma = 4.0$ (softer Gaussian targets) was compared to $\sigma = 2.0$. While training KL was lower with $\sigma = 4.0$ (softer targets are easier to fit), validation NSS was worse (2.88 vs 3.35 at best epoch). Softer targets allow the model to produce diffuse predictions that incur less KL penalty but place less probability mass at the true fixation. All subsequent experiments use $\sigma = 2.0$.

At the time of writing, the following runs are in progress:

- **200k NLL, full 15 epochs**: characterises the scaling curve with the best loss function to its natural convergence point.

## 7. Conclusion

We presented a DINOv2-based history-conditioned fixation prediction model trained on large-scale synthetic scanpaths. The main findings are:

1. **The model scales with data**: increasing training images from 50k to 200k yields a 22% improvement in NSS, with no plateau observed at 200k.
2. **NLL loss substantially outperforms KL divergence** (+0.37 NSS), as it directly optimises the evaluation objective rather than fitting a Gaussian proxy.
3. **Enriching fixation tokens with visual features does not help**, suggesting the cross-attention architecture already accesses this information implicitly.
4. **Throughput engineering enabled 4× faster training** through vectorisation, decoder redesign, and encoder deduplication, making large-scale experiments practical.
